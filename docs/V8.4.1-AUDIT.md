# V8.4.1 Implementation Audit

This audit maps the V8.4.1 acceptance surface to code and executable evidence.
It distinguishes deterministic system behavior from real-model routing and
browser verification. A model or browser result is never inferred from a unit
test.

`backend/tests/test_v841_scenarios.py`.

## Conversation and model-routing audit

The genuine model path adds tools through the existing `MemoryAgent._tools_for()`
registration point. It does not add a hidden natural-language dispatcher.
`test_v841_real_model.py` requires a real Ollama server and asserts:

- provider is not demo/degraded;
- the model emits a `TOOL_DECISION` for a learned inspection/correction tool;
- a corresponding `TOOL_RESULT` exists;
- there is no `TOOL_FAILED` marker;
- the answer or persisted lifecycle is grounded in the tool result.

During final verification, the configured probe at `http://localhost:11434`
failed with `ConnectError`. The two real-model tests therefore reported
**SKIPPED — V8.4.1 real-model behavior NOT VERIFIED**. Deterministic or scripted
coverage is not relabelled as real-model success.

## Honesty and safety audit

- No promotion solely from model output or frequency.
- No Experience without real observation evidence.
- No `SUPPORTED`/`CONTRADICTED` reputation update without evidence.
- No background promotion.
- No retrieval of retired, contradicted or outdated objects.
- No current-world precondition assumption when the required state is absent.
- No cross-user evidence linking, reads, corrections or causal traversal.
- No private chain-of-thought endpoint; explanations are evidence summaries.
- No global Principle from ordinary user evidence.
- No new external action, connector or research capability.
